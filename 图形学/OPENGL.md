# 前提

**OpenGL是一套跨语言，跨平台的2D/3D图形渲染API。 本质上是一套图形渲染规范，由显卡厂商在驱动里实现，应用程序通过调用OpenGL函数让GPU完成三角形绘制、纹理贴图、光照、阴影等渲染工作。**

3.3核心模式   Qt6.6MinGw（无需配置第三方库如GLFW+GLAD，因为Qt内部封装好了）

**GLFW**：解决操作系统层面的不同（如在窗口上调用windows或linux的绘制接口）
	1. 创建窗口； 2. 定义上下文； 3.处理用户输入

**GLAD**：使得代码可以用于不同的OpenGL驱动（原理是获取显卡在当前上下文状态下的OPENGL函数的地址）
	1.OpenGL本身只是规范/标准； 2.各个显卡厂家具体实现方式可以不同
	如果没有类似GLAD的库，windows下：需要通过函数指针调用显卡的函数，但是显卡驱动具体函数的地址，运行时才知道


# 什么是OpenGL

OpenGL主要被认为是一个API，它为我们提供了大量可用于操作图像的函数。然而，OpenGL本身并非一个API，而仅仅是由Khronos开发和维护的一种规范；
OpenGL核心是一个C库，同时也支持多种语言的派生

OpenGL的实现是图形渲染API，并不是图形引擎，甚至不是IG(Image Generator)

核心模式（core-profile）：也叫可编程管线，提供了更多的灵活性，更高的效率，更重要的是可以更深入的理解图形编程。
