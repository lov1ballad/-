构造函数：
C++的构造函数主要有六种：默认构造、参数化构造、拷贝构造、移动构造、委托构造、继承构造
核心的区别是出发诗句和资源处理方式不同：默认构造负责零初始化，拷贝构造复制资源，移动构造转移资源所有权，委托构造复用初始化逻辑，继承构造透传基类初始化。

1.默认构造，未定义构造函数时自动生成，如果定义了其他构造函数后需要=default显示声明，没有参数；

2.参数化构造，不会自动生成，用户自定义，带参创建对象；

3.拷贝构造函数，className(const ClassName&)，未定义时自动生成（浅拷贝）。使用已有对象初始化新对象（可分为深拷贝和浅拷贝）；
核心作用实现对象复制，并防止浅拷贝导致的内存错误，参数必须是同类对象的引用（通常使用const修饰）。

| ClassName(const ClassName& other);              | 最常见形式        |
| ----------------------------------------------- | ------------ |
| **ClassName(ClassName& other);**                | **非const版本** |
| **ClassName(volatile ClassName& other);**       |              |
| **ClassName(const volatile ClassName& other);** |              |
参数必须是引用，不能值传递，否则会无限递归调用导致栈溢出。因为自定义类型按值传参时，编译器必须调用该类型的拷贝构造来创建形参副本。

如果类中包含指针成员并动态分配了堆内存，默认的浅拷贝会导致两个对象的指针指向同一块内存，析构的时候会重复释放，导致程序崩溃，此时必须自定义拷贝构造函数。

4.移动构造，className(ClassName&&)，未定义拷贝/移动操作且未定义析构时自动生成，窃取临时对象资源，避免深拷贝；
4.1参数必须是右值引用：只能绑定临时对象（纯右值）或被std::move转换后的对象（将亡值）；
4.2必须标记noexcept：如果移动可能抛异常，std::vecotr等标准容器扩容时会回退到拷贝构造，导致优化失效；
4.3必须将源对象资源指针置空：防止析构时重复释放同一块内存；
4.4隐式生成规则：如果类自定义了析构函数、拷贝构造或拷贝赋值中的任意一个，编译器不会自动生成移动构造。

触发场景：

| 场景          | 示例                                | 触发类型 |
| ----------- | --------------------------------- | ---- |
| 临时对象初始化     | StringBox s = StringBox("hello"); | 移动构造 |
| std::move转换 | StringBox s2 = std::move(s1);     | 移动构造 |
| 函数返回局部对象    |                                   | 移动构造 |
|             |                                   | 移动构造 |
|             |                                   |      |


5.委托构造：不会自动生成，一个构造函数调用同类其他构造函数，避免重复代码；

6.继承构造：不会自动生成，需using声明，派生类直接使用基类构造函数
