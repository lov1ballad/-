| 内核空间    | 操作系统占用，用户无法控制   |                          |

| 环境变量    | 程序的输入参数等        |                          |

| bss段    | 未初始化的全局变量和静态变量  |                          |
| data段   | 已初始化的全局变量和静态变量  |                          |
| rodata段 | const、字符串常量     |                          |
| text段   | 代码段             |                          |

## new和malloc区别？

### new/delete
new是C++运算符，一次操作完成两件事：先通过operator new 分配内存，再在这块内存上调用构造函数初始化对象。delete先调用析构函数再释放内存空间。

### malloc/free
malloc是C标准库函数，只负责分配一块指定大小的原始内存，不调用任何构造函数。free只释放内存空间，不调用析构函数
