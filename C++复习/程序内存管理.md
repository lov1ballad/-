![[程序内存空间分布.png]]

| 内核空间    | 操作系统占用，用户无法控制   |                          |
| ------- | --------------- | ------------------------ |
| 环境变量    | 程序的输入参数等        |                          |
| 栈空间     | 局部变量，函数参数等，向下生长 | 编译器管理，空间小，无碎片，线程私有，天然安全  |
| 缓冲区     | 可用空间            |                          |
| 堆空间     | new/malloc，向上分配 | 手动管理，空间大，存在内存碎片，线程共享，需要锁 |
| 内存映射区   | mmap，动态链接库      |                          |
| bss段    | 未初始化的全局变量和静态变量  |                          |
| data段   | 已初始化的全局变量和静态变量  |                          |
| rodata段 | const、字符串常量     |                          |
| text段   | 代码段             |                          |
