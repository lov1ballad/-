## new和malloc区别？

### new/delete
new是C++运算符，一次操作完成两件事：先通过operator new 分配内存，再在这块内存上调用构造函数初始化对象。delete先调用析构函数再释放内存空间。new失败抛出bad_alloc异常；new成功返回具体类型指针。

new MyClass(10)；这一行代码，编译器拆为两步：第一步，调用operator new(sizeof(MyClass))分配内存——这个函数内部通常也是调用malloc；第二步，在分配到内存地址上调用MyClass的构造函数。所以new的完整调用链是：new——operator new——malloc——mmap/brk(操作系统底层)
### malloc/free
malloc是C标准库函数，只负责分配一块指定大小的原始内存，不调用任何构造函数。free只释放内存空间，不调用析构函数。malloc失败返回NULL。malloc成功返回void* 需要强转。

malloc(sizeof(MyClass))只做一件事：向操作系统申请一块指定大小的原始内存，返回void* 指针。这块内存是垃圾值，没有任何初始化。

### malloc分配内存后手动调用构造？
定位new，placement new：MyClass* obj = new(mem) MyClass(10); 其中mem是malloc返回的指针。placement new 不分配内存，只在指定的地址上调用构造函数。析构时也要手动调用obj->!MyClass()，然后再free(mem)。内存池原理。

### placement new 的作用？
和普通new的区别关系：
	普通new MyClass(10)编译器会拆成两步：1.先调用operator new(sizeof(MyClass))分配内存，；2.在这块内存上调用构造函数。
	Placement new跳过了第一步，直接我在你提供的内存地址上调用构造函数。
底层实现：
	标准库中有一个特殊的operator new 重载：void* operator new(size_t, void* ptr)noexcept{return ptr；}，他什么都不做，直接返回你传入的指针。
placement new 构造的对象，内存可能来自栈上也可能来自堆还有可能来自内存池、共享内存段等。如果对该对象调用delete obj，行为可能是未定义的。正确做法是：先手动析构obj->~MyClass()，再用原始方式释放内存（栈上的自动回收，内存池的还给池子，new 的用delete）

### 标准库哪些地方用了定位new
1.std::vector 扩容时：分配新的更大内存块，然后用placement new在新的内存上移动构造旧元素。
2.std::variant: 在同一块内存上构造了不同类型的对象，先调用析构销毁旧对象，再用定位new构造新对象来完成类型的切换。
3.所有内存池/对象池的实现都依赖定位new。内存池的核心思想是：预分配一大块内存，按需切割使用；切割出来的小块内存上构造对象就需要依靠定位new，销毁对象就靠手动析构。这种做法就避免了频繁调用malloc/free的开销和内存碎片问题。

PS：
1.placement new 不会失败，标准的placement operator new标记了noexcept承诺不会抛异常，只是返回你传入的指针，不做任何可能失败的操作。但是构造函数本身可能会抛异常——如果构造函数执行时抛异常了，对象就没有被成功构造，那么就不需要调析构函数，但内存仍然需要按原始方式释放。但是会存在构造函数中已经new int(10)这种操作执行成功了的情况，如果构造函数抛异常，那么操作系统会寻找签名匹配的placement operator delete来清理，标准库中的operator delete是空操作，所以这种情况下就会出现资源泄露(new的int泄露)
