SQL函数的作用：
1. 执行数据运算；
2. 修改单个数据项；
3. 操作输出进行 行分组；
4. 格式化显示的日期和数字；
5. 转换列数据类型。

SQL函数有**输入参数**，并且**有且只有一个返回值**。

分类：
![[Pasted image 20261014163303.png]]


**单行函数**：仅对单个行进行运算，并且每行返回一个结果。
	常见的函数类型：字符、数字、日期、转换；

**多行函数**：多行函数能够操作成组的行，每个行组给出一个结果，也称组函数；


# 单行函数

**接受多个参数并返回一个值；**

**可以修改数据类型；

## 字符函数

 ![[Pasted image 20261014164414.png]]


**大小写处理函数：**

| 函数                  | 描述         |
| ------------------- | ---------- |
| LOWER(s) 或 LCASE(s) | 将字符串s转换为小写 |
| UPPER(s) 或 UCASE(s) | 将字符串s转换为大写 |
![[Pasted image 20261014170559.png]]![[Pasted image 20261014171055.png]]


**字符处理函数：**


| 函数                     | 描述                            |                                          |
| ---------------------- | ----------------------------- | ---------------------------------------- |
| LENGTH(s)              | 返回字符串s的长度                     |                                          |
| CONCAT(s1,s2....sn)    | 字符串s1,s2等多个字符串合并为一个字符串        |                                          |
| LPAD(s1,len,s2)        | 在字符串s1的开始处填充字符串s2，使字符串长度达到len | select lpad("oldlu",8,'x')------xxxoldlu |
| LTRIM(s)               | 去掉字符串s开始处的空格                  | select ltrim("    oldlu")------oldlu     |
| REPLACE(s,s1,s2)       | 将字符串s2替代字符串s中的字符串s1           | select ltrim("oldlu","o","O")------Oldlu |
| REVERSE(s)             | 将字符串s的顺序反过来                   |                                          |
| RPAD(s1,len,s2)        | 在s1的结尾处添加字符串s2，使字符串s1的长度达到len |                                          |
| RTRIM(s)               | 去掉字符串s结尾处的空格                  |                                          |
| SUBSTR(s,start,length) | 从字符串s的start位置截取长度为length的子字符串 |                                          |
| SUBSTRING(s,length)    | 从字符串s的start位置截取长度为length的子字符串 |                                          |
