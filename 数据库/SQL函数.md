SQL函数的作用：
1. 执行数据运算；
2. 修改单个数据项；
3. 操作输出进行 行分组；
4. 格式化显示的日期和数字；
5. 转换列数据类型。

SQL函数有**输入参数**，并且**有且只有一个返回值**。

分类：
![[Pasted image 20261014163303.png]]


**单行函数**：仅对单个行进行运算，并且每行返回一个结果。
	常见的函数类型：字符、数字、日期、转换；

**多行函数**：多行函数能够操作成组的行，每个行组给出一个结果，也称组函数；

**ROUND（colunm|expression，n）函数**
	四舍五入列、表达式或者n位小数的值。如果第二个参数是0，或缺省，值被四舍五入为整数，如果第二个参数是2，则被四舍五入为两位小数。如果第二个参数是-2，值被四舍五入到小数点左边两位。

## 日期函数

在MySQL中允许直接使用字符串表示日期，但是要求字符串的日期格式必须为：“YYYY-MM-DD HH:MI:SS”或者"YYYY/MM/DD HH:MI:SS"；（**内部支持隐式从字符串转为日期格式数据**）


| 函数名                   | 描述                        | 实例                                                 |
| --------------------- | ------------------------- | -------------------------------------------------- |
| CURDATE()             | 返回当前日期                    |                                                    |
| CURTIME()             | 返回当前时间                    |                                                    |
| CURRENT_DATE()        | 返回当前日期                    |                                                    |
| CURRENT_TIME()        | 返回当前时间                    |                                                    |
| DATE()                | 从日期或日期时间表达式中提取日期值         | select date("2017-06-15");->2017-06-15             |
| DATEDIFF(d1,d2)       | 计算日期d1到d2之间相隔的天数          | select datediff("2001-01-01","2001-02-02") -> -32  |
| DAY(d)                | 返回日期值d的**日期**部分           |                                                    |
| DAYNAME(d)            | 返回日期d时星期几，如Monday，Tuesday |                                                    |
| DAYOFMONTH(d)         | 计算日期d是本月的第几天              |                                                    |
| DAYOFWEEK(d)          | 日期d今天是星期几，1星期日，2星期一       |                                                    |
| DAYOFYEAR(d)          | 计算日期d是本年的第几天              |                                                    |
| HOUR(t)               | 返回t中的小时值                  |                                                    |
| LAST_DAY(d)           | 返回给定日期的那一月份的最后一天          | select last_day("2017-06-20")-> 2017-06-30         |
| MONTHNAME(d)          | 返回日期当中的月份名称               |                                                    |
| MONTH(d)              | 返回日期d中的月份值，1-12           |                                                    |
| NOW()                 | 返回当前**日期和时间**             |                                                    |
| SECOND(t)             | 返回t中的秒值                   |                                                    |
| SYSDATE()             | 返回当前**日期和时间**             |                                                    |
| TIMEDIFF(time1,time2) | 时间差值                      | select timediff("13:10:11","13:10:10") -> 00:00:01 |
| TO_DAYS(d)            | 计算日期d距离0000年1月1日的天数       |                                                    |
| WEEK(d)               | d是本年第几个星期，0-53            |                                                    |
| WEEKDAY(d)            | d是星期几，0-6,0是星期一           |                                                    |
| YEAR（d）               | 返回年份                      |                                                    |
