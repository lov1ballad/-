
![[Pasted image 20261014162933.png]]**不同的关系型数据库对SQL函数的实现是不一样的，函数名以及支持情况也不一样。**

SQL函数的作用：
1. 执行数据运算；
2. 修改单个数据项；
3. 操作输出进行 行分组；
4. 格式化显示的日期和数字；
5. 转换列数据类型。

SQL函数有**输入参数**，并且**有且只有一个返回值**。

分类：
![[Pasted image 20261014163303.png]]


**单行函数**：仅对单个行进行运算，并且每行返回一个结果。
	常见的函数类型：字符、数字、日期、转换；

**多行函数**：多行函数能够操作成组的行，每个行组给出一个结果，也称组函数；

聚合函数：对行的分组进行操作，对每组给出一个结果。如果在查询中没有指定分组，那么聚合函数则将查询到的结果视为一组。（作用在多条数据上但只返回一个结果）

## COUNT函数

返回分组中的总行数

COUNT函数的三种格式：
1. COUNT(* )：返回表中满足SELECT语句的所有列的行数，包括重复行，包括有空值列的行；
2. COUNT(expr)：返回在列中的由EXPR指定的非空值的数；
3. COUNT(**distinct** expr)：返回在列中的由expr指定的唯一非空值的数；

![[Pasted image 20261016230535.png]]

**组函数和NULL值**：

### 在组函数中使用IFNULL函数

**对有佣金的雇员进行平均佣金计算**
SELECT AVG(**IFUNLL**(comission_pct,0)) from employyes;
