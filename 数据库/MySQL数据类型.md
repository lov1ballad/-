
# MySQL数据类型分类

## 整数类型

1. tinyint(m)：1个字节，范围（-128——127）
2. smallint(m)：2个字节，范围（-32768——32767）
3. mediumint(m)：3个字节，范围（-8388608——8388607）
4. int(m)：4个字节
5. bigint(m)：8字节

数值类型中的长度m指的是显示长度，只有字段指定了zerofill时有用；
int(3)，表示显示长度为3，如果实际值是2，列指定了zerofill，查询结果就是002，左边用0
来填充。

## 浮点类型

1. float(m,d)：单精度浮点型，8位精度（4字节），m总个数，d小数位；
2. double(m,d)：双精度浮点型，16位精度（8字节），m总个数，d小数位；
**使用浮点类型必须要给括号中的参数。如float(5,2)表示小数保留两位，整数则为三位**
## 字符类型

1. char(n)：固定长度，最多255个字符；
2. tinytext：可变长度，最多255个字符；
3. varchar(n)：可变长度，最多65535个字符；
4. text：可变长度，最多65535个字符；
5. mediumtext：可变长度，最多2的24次方-1个字符；
6. longtext：可变长度，最多2的32次方-1个字符；

**char和varchar区别**：
1. char长度固定，n为字符的总长度，每条数据占用等长字节空间，char(5)如果是a，则在a前面补齐4个空格；适用场景为手机号，身份证等；
2. varchar可变长度，可以设置最大长度；varchar(5)如果是a，不会补齐空格；
3. text不设置长度，不知道属性最大长度时适合用
